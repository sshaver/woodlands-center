# Codex Build Task Breakdown

Use this after reading `CODEX_MASTER_PROMPT.md`.

## Task 1 — Repository and data foundation

- Initialize app.
- Add TypeScript, routes, global styles, design tokens.
- Add content schemas and fixture data.
- Add `.env.example`.
- Add build/type/lint scripts.

## Task 2 — Global shell and navigation

- Header, mobile dock, mobile menu, alert banner, footer, popover CTA.
- Active states and responsive behavior.

## Task 3 — Events templates

- Home/Events page with carousel/list toggle.
- Event detail page with all required fields and policy quick links.
- Event fixtures for sample artists shown in comps plus generic events.

## Task 4 — Landing page/block system

- Block renderer.
- Hero, video, tabs, media/text, stats, story block, HTML, CTA band.
- Season Seats landing page and reusable season seats block.

## Task 5 — Mission and funding/outreach pages

- Mission landing page with full page sections.
- Support the Arts pages.
- Funding the Arts pages.
- Arts Outreach pages, including seasonal/hidden tab behavior.
- Arts Shows pages.

## Task 6 — Plan Your Visit and AI/search

- Plan Visit template and topic content.
- Search endpoint over internal content.
- Results UI with source links.

## Task 7 — Story Hub

- Story hub light theme.
- Featured/recent/large story cards.
- Topic filters and story detail pages.

## Task 8 — Footer pages and blank template

- Staff, Leadership, History, Press, Work, Rent, Volunteer, Sponsors.
- Blank/Flow template.
- External and popover footer links.

## Task 9 — QA and documentation

- Responsive verification against comps.
- Accessibility pass.
- Content validation.
- README with local run, build, deployment, CMS editing notes, and integration placeholders.
